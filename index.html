오늘 할 일

끝난 작업은 눌러서 완료 체크해주세요. 한 번 더 누르면 취소돼요.

주간 스케줄

① 왼쪽 작업 목록에서 작업을 고르고 ② 표에서 사람 × 요일 칸을 누르면 그날 할 일로 들어가요. 같은 작업을 여러 번 눌러도 돼요.
칸 안 작업의 ✕를 누르면 빠지고, 칸 아래 근무시간을 누르면 이번 주 그날만 근무시간을 바꿀 수 있어요. 작업시간이 근무시간을 넘으면 빨간색이 돼요.

이번 주 필요 재료

레시피가 연결된 작업(예: 바스크 2배합)만 계산돼요. 필요한 양과 지금 재고를 비교해서 부족하면 몇 개를 발주해야 하는지 알려드려요.

작업 목록

작업은 한 번만 등록해두면 매주 골라서 배정할 수 있어요. 레시피를 연결하면 "이번 주 필요 재료"가 자동으로 계산돼요. (예: 에그타르트 밀기 → 에그타르트 레시피, 2배합)

기본 근무시간

요일별로 평소 몇 시부터 몇 시까지 일하는지 적어두세요. 9-18, 8:30-17처럼 쓰고, 비워두면 휴무예요. 매주 시간표에 자동으로 들어가고, 특정 주만 다르면 시간표에서 이름 옆 시간을 누르면 돼요. (성진님처럼 다른 일과 겸하면 우리 작업을 하는 시간대만 적어주세요.)

매장 휴무 요일

쉬는 요일을 눌러서 표시해두면 표 위쪽에 그날 출고하는 매장만 보여요.

레시피북

제품을 고르고 배합 수를 넣으면 재료 양이 자동으로 곱해져요.

재료 계산기 · 발주 계산

만들 제품과 배합 수를 담으면 필요한 재료 총량, 지금 재고, 부족분, 발주할 개수를 계산해요. 예: 바스크 2배합 + 말차바스크 3배합을 담으면 생크림·크림치즈가 얼마나 필요한지 바로 나와요.

⚠ 재고 부족 알림

재고 입고 / 수정

재고는 "개"(포장 단위)로 관리해요. 예: 생크림 500ml짜리를 6개 받았으면 6을 입력하세요. (재료별 용량은 아래 "재료 등록"에서 정해요.)

재료 등록

새 재료를 추가하거나, 아래 목록에서 "수정"을 눌러 이름·가격·거래처 같은 상세 정보를 고칠 수 있어요. 재고 수량만 빠르게 바꾸고 싶으면 위 "재고 입고/수정"이나 아래 목록에서 숫자를 직접 클릭하세요.

등록된 재료

"현재 재고" 숫자를 클릭하면 그 자리에서 바로 수정할 수 있어요.

최근 재고 변동 내역

완제품 재고

업무일지에 생산을 기록하면 자동으로 쌓이고, 카페 출고를 등록하면 오래 만든 것부터 자동으로 차감돼요. (이미 등록된 출고를 나중에 수정·삭제해도 이 수량은 자동으로 다시 계산되지 않아요.)

거래처 관리

재료 등록 시 거래처를 지정해두면 재료별로 어디서 사는지 기록해둘 수 있어요.

발주 사진으로 입고

마켓봄·천년스마트발주 등에서 주문한 발주서를 캡처해서 올리면 사진 속 글자를 자동으로 읽어와요.
읽어온 내용은 아래 상자에 채워지는데, 사진 인식이 완벽하지 않을 수 있으니 상품명 | 수량 | 금액 형식에 맞게 한 번 확인·수정한 뒤 "파싱하기"를 눌러주세요.
매칭 단계에서는 이미 등록된 원재료로만 연결돼요 (새 재료를 자동으로 만들지 않아요) — 매칭되는 재료가 없으면 자동으로 "건너뛰기"로 남아요.
(직접 타이핑해서 붙여넣어도 돼요.)

재료 매칭 확인 후 일괄 입고

입고 수량은 상품명의 용량(예: 1000ml, 15kg) × 수량으로 자동 계산했습니다. 재료의 등록 단위와 다르면 직접 수정하세요.

직원 관리

인건비 계산에 사용됩니다 (배합 소요시간 × 시급). 시급은 관리자 모드에서만 보입니다.

직원 랭킹 🏆

업무일지에 공정을 기록할 때마다 포인트가 쌓여요!

업무일지 작성

배합 수는 "이 제품을 총 몇 배합 만들었는지"를 뜻해요 (재료·재고 차감 기준이라 딱 한 번만 정확히 입력하면 돼요).
공정(반죽→굽기→컷팅/포장)은 같은 생산 건이면 전부 이 업무일지 하나에 같이 담아주세요. 굽기·컷팅/포장이 다른 날 끝나면, 새로 만들지 말고 아래 "업무일지 목록"에서 이 일지를 수정해서 공정만 추가해주세요 — 배합 수를 그대로 두면 재고는 다시 차감되지 않아요.
공정별로 담당자·소요시간·수량이 다르면 아래에서 하나씩 담아주세요. 반죽/굽기/컷팅·포장을 전부 오늘 한다면 순서대로 다 담고 저장하면 돼요.
공정 "수량"은 그 공정만의 실제 작업량이에요 — 반죽은 보통 "3배합", 굽기·컷팅/포장은 실제로 구운/자른/포장한 "150개"처럼요. 이 수량은 기록용일 뿐, 재고 차감은 위 "배합 수"로만 계산돼요. (안 남겨도 저장은 돼요.)
